01 / 配置地图

两个关键目录，各管各的

🏠

全局配置目录

~/.config/opencode/
（你的电脑上是 C:\Users\user\.config\opencode\）

存放所有项目共享的设置：API 密钥、MCP 服务、全局技能、长期记忆。相当于「系统偏好设置」。

📁

项目配置目录

项目根目录/.opencode/
（你的项目是 D:\OpenCode\.opencode\）

存放单个项目专属的技能、记忆。可以随项目一起 Git 提交，团队共享。

02 / 启动时间线

你输入 opencode 后发生了什么？

Step 1

读取全局配置

加载 C:\Users\user\.config\opencode\opencode.json，获取 API 提供商（zhipuai）、模型、权限规则、MCP 服务列表。

Step 2

合并项目配置

扫描项目目录的 opencode.json 和 .opencode/，项目级配置会覆盖全局配置的同名项。

Step 3

扫描 Skill 目录

遍历全局 + 项目两层的 skills/*/SKILL.md，把所有 Skill 的 name 和 description 注册到工具列表。

Step 4

启动 MCP 服务

对每个配置的 MCP 服务（context7、gh_grep、web-reader、zai-mcp-server），建立连接并获取其提供的工具列表。

Step 5

组装 System Prompt

把「角色说明 + 可用工具列表 + 权限规则 + AGENTS.md + Skill 列表」拼成完整的系统提示词。

Step 6

加载记忆

读取 memories/long_term_memory.md（用户偏好、项目信息等），注入上下文，让 AI 记住你的习惯。

Step 7

就绪，等待输入

TUI 界面渲染完成。你现在可以输入问题了——一切配置已就位。

03 / 配置文件解析

你的 opencode.json 里都有什么？

opencode.json · 你的实际配置
{
  "$schema": "opencode.ai/config.json",

  // ① API 提供商
  "provider": {
    "zhipuai": { "api": "https://open.bigmodel.cn/..." },
    "zhipuai-vision": { /* 视觉模型 */ }
  },

  // ② 工具权限
  "permission": {
    "bash": "allow",
    "edit": "allow",
    /* ...全部 allow */
  },

  // ③ MCP 服务
  "mcp": {
    "context7": { "type": "remote", "url": "..." },
    "gh_grep": { "type": "remote", "url": "..." },
    "web-reader": { /* 远程 MCP */ },
    "zai-mcp-server": { "type": "local" }
  },

  // ④ 启用哪些 MCP
  "tools": {
    "web-reader": true,
    "context7": true,
    "gh_grep": true,
    "zai-mcp-server": true
  }
}

🔐 provider（提供商）

告诉 OpenCode 用哪家 AI 模型。你用的是智谱 AI（GLM 系列）。也可以同时配多个提供商切换使用。

🛡️ permission（权限）

每个工具的安全开关。allow=放行、ask=需确认、deny=禁止。你的配置全部放行。

🔌 mcp（外部工具服务）

配置远程或本地的 MCP 服务。remote=云端服务，local=本地启动的进程。

🔧 tools（工具开关）

控制哪些 MCP 服务的工具对 AI 可见。true=启用，false=禁用。

04 / 上下文组装

你的问题被包装成了什么？

当你输入一句话后，OpenCode 并不是直接把这句话发给 AI。它会在前面拼上一个巨大的「系统提示词」，像这样：

角色定义
System: 你是 opencode，一个 AI 编程助手...
工具列表
内置: bash, read, write, edit, grep, glob...
MCP 工具
MCP: context7_query, gh_grep_search, webReader...
Skill 列表
Skills: pdf, docx, pptx, xlsx, mcp-builder...
AGENTS.md
项目规则、代码风格、测试命令...
长期记忆
用户偏好中文、Windows 环境...
你的消息
帮我写一个函数

💡 这整条「三明治」就是 AI 实际收到的内容。你的问题只占很小一段，但前面的上下文决定了 AI 怎么回答。

05 / 配置优先级

谁说了算？

层 来源 路径 优先级
1远程组织配置.well-known/opencode最低
2全局配置~/.config/opencode/opencode.json↑
3项目配置项目/opencode.json↑
4.opencode 目录项目/.opencode/↑
5环境变量覆盖OPENCODE_CONFIG_CONTENT最高

➡ 规则很简单：越靠近项目的配置，优先级越高。就像公司制度 > 部门规章 > 个人偏好，局部覆盖全局。

07 / 记忆系统

AI 怎么「记住」你的习惯？

🧠

长期记忆

memories/long_term_memory.md

跨会话持久保存。记录你的编码偏好、常用语言、项目信息。每次启动都会加载。

💬

会话上下文

当前对话的完整历史。

你说的每句话、AI 的每次回复、工具调用的结果，都累积在上下文窗口中。超出时会自动压缩（compaction）。

📑

AGENTS.md

项目根目录的规则文件。

相当于给 AI 的「项目说明书」——告诉它代码风格、测试命令、项目架构。可以被 Git 管理，团队共享。

08 / 记住这三条

知识锚点

01

双层配置

全局 ~/.config/opencode/ 管个人偏好，项目 .opencode/ 管团队规则。项目配置覆盖全局。

02

上下文是拼图

System Prompt = 角色定义 + 工具列表 + Skill + MCP + 记忆 + AGENTS.md。你的问题只占一小段。

03

记忆跨越会话

memories/long_term_memory.md 让 AI 记住你的偏好，即使关掉 OpenCode 再打开也不会忘。
