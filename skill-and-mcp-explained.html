Skill · 菜谱
📖

本质：一份 Markdown 指南

存放在 .opencode/skills/ 目录。包含触发条件、工作步骤、输出格式。AI 读了就知道"这道菜怎么做"。

MCP · 万能插座
🔌

本质：一套标准通信协议

Model Context Protocol。让 AI 通过 Tool / Resource / Prompt 三种原语，与真实的外部服务（API、数据库、文件系统）对话。

05 / 记住这三条

知识锚点

01

Skill = 知识

它是一份指南，告诉 AI 在特定场景下应该怎么思考、怎么规划步骤。

02

MCP = 能力

它是一套协议标准，让 AI 能连接真实世界——调 API、读写文件、操作数据库。

03

配合才有效

只有知识没有能力 = 纸上谈兵；只有能力没有知识 = 蛮力乱撞。两者缺一不可。
